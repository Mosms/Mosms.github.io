# Homepage of Bo FU (付博)

## About Me

Now from [SJTU](https://en.sjtu.edu.cn), China.

## Template

This homepage uses the [Minimal Light](https://github.com/yaoyao-liu/minimal-light)
academic homepage theme.

## Local development

This site is generated by Jekyll 3.9.5 through the `github-pages` gem.

### Docker (recommended)

Start Docker Desktop, then run:

```powershell
docker compose up --build
```

Open <http://localhost:4000>. Changes to pages, posts, layouts, includes and
stylesheets are rebuilt automatically. Stop the server with `Ctrl+C`; remove the
container with `docker compose down`.

### Native Ruby

Install Ruby 3.2 with Devkit, then run:

```powershell
gem install bundler -v 2.5.7
bundle install
bundle exec jekyll serve --livereload
```

Open <http://localhost:4000>.
